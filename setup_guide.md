# How to setup a proper development environment
## Windows
### CMake based setup in VS Code
#### Pre-requirements
It is recommended to install the following using `winget`.
- Microsoft.VisualStudioCode
- Kitware.CMake
- Ninja-build.Ninja
- Microsoft.Git

And download and install:
- Build Tools for Visual Studio 2022 (For now)

The MS Build Tools installer does not add toolchain paths to the system Path.
